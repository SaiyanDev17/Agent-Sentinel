# Agent Builder Setup Guide

Step-by-step instructions for configuring all agents in Google Cloud Agent Builder.

> This guide will be filled in during Phase 2 tasks.

## Prerequisites

- Google Cloud account with free trial activated
- Project `agent-sentinel` created
- All 6 APIs enabled (Vertex AI, Agent Builder, Cloud Run, Cloud Build, Artifact Registry, Secret Manager)

## Agents to Create

1. **AidAssist** — Target agent (disaster relief)
2. **RedTeamGenerator** — Adversarial scenario creator
3. **EvalJudge** — Response evaluator
4. **TraceInvestigator** — Phoenix trace inspector
5. **ImprovementPlanner** — Prompt/tool fix recommender
6. **QACommander** — Top-level orchestrator
7. **ReleaseManager** — Final release decision maker
